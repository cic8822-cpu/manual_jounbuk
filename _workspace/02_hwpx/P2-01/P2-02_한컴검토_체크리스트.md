# P2-02 한컴 검토 체크리스트

- **목적**: P2-01에서 기술 검증(`fill -j`→`validate`→`render`→재파싱 왕복, 이미지 바이트 전수 확인)을 통과한 F-007·F-024·F-013 3종 6개 산출물을 한컴오피스에서 직접 열어 육안으로 최종 확인함.
- **작성자**: 문서자동화 담당(document-automation-engineer). **이 문서는 체크리스트일 뿐이며, 실제 확인·서명은 사람(행정실 직원·품질검토 담당)이 수행함. 이 문서 작성만으로 P2-02를 완료로 표시하지 않음.**
- **대상 파일**: `artifacts/hwpx/P2-01/`의 6개 HWPX(아래 표).
- **SVG 미리보기(참고용, 최종 판단 근거 아님)**: `_workspace/02_hwpx/P2-01/PDF미리보기/`에 파일별 1개씩 있음. **PDF가 아니라 SVG임** — 이 환경에 kordoc PDF 렌더가 요구하는 `puppeteer-core`가 kordoc이 실제로 참조하는 경로에 설치되지 않아(격리 설치 후 `NODE_PATH`로 연결 시도했으나 인식 안 됨) PDF 생성이 불가능했고, Chromium 의존성이 없는 SVG로 대체함. SVG는 브라우저에서 열람 가능하며 kordoc 자체 리플로우 조판이므로 **한컴 실제 조판과 다를 수 있음 — 참고용 사전 확인 자료일 뿐, 한컴 화면·PDF가 최종 판단 근거임.**

- [ ] 특수문자·기호(○○, ㅇ, □, %, ㎝, 물결표 등)가 깨지지 않았는가

## F-013 전용 체크 항목 (가장 주의 깊게 확인 필요)

- [ ] **표 개수 불일치**: kordoc 렌더는 **표 14개**로 보고하나 원본은 **표 11개**임. 한컴에서 실제로 몇 개의 표로 인식되는지 확인하고, 불일치가 있다면 어느 절(가~자)에서 표가 분할되거나 추가로 생겼는지 특정할 것
- [ ] **페이지 분량**: kordoc 렌더는 **12쪽**(원본 추정 11쪽과 유사하나 정확한 원본 쪽수는 한컴에서 재확인 필요). 줄바꿈·표 분할 위치가 부자연스럽지 않은지 확인
- [ ] **페이지에 걸친 표 경고**: kordoc render가 "⚠️ 페이지에 걸친 표 — 분할 지오메트리가 없어 시작 페이지 영역만 region으로 기록"을 보고함(섬유혼용률 표(19행) 등 긴 표가 페이지 경계를 넘는 경우로 추정). 한컴에서 해당 표가 페이지 경계에서 **잘리거나 헤더 행이 중복/누락되지 않는지** 직접 확인
- [ ] **이미지 배치(55개소, 고유 파일 41개)**: 8개 디자인 표("가~사")의 의류·와펜 이미지와 2개 사진 갤러리 표("아·자")의 사진이 **모두 실제 사진으로 보이는지**(빈 칸·깨진 이미지 아이콘·1×1 픽셀처럼 안 보이는 이미지가 없는지) 전수 확인. *2026-09-19 기술 검증에서 재추출 이미지의 바이트 크기를 41개 전수 확인해 스텁 0개를 확인했으나, 이는 파일 내부 데이터 검증이며 한컴 화면에서 실제로 보이는 모습은 별도로 확인해야 함*
- [ ] 이미지 크기·비율이 셀 안에서 과도하게 늘어나거나 잘리지 않는가(특히 와펜 이미지처럼 정사각형 비율이 유지돼야 하는 것들)
- [ ] "학교명：검증중학교" 필드만 fill로 치환됐고, 제목의 "○○○○학교"·본문의 "OOOO학교"(3번 항목 소제목)는 표준 예시 문구로 의도적으로 남겨둔 것이 맞는지 확인(9.2절 참고 — F-013은 라벨 기반 fill이 학교명 외에는 구조적으로 적용되지 않는 문서)

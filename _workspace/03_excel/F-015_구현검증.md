# F-015 정량적 평가 구현·검증 (부분 구현 — 저장 연동 차단)

- **상태**: `부분 구현 — 출력 경로만 검증 통과, 저장하기()/수정하기()/불러오기() 연동은 원인 미상 무한 대기로 제거함`
- **Form ID**: `F-015`
- **원본 대조 대상**: `교복4차 (2)/교복 매뉴얼 작성서식0908(안정구 추가).hwpx`의 `[9-4] [붙임 3_1] [1단계] 정량적 평가`
- **원본 보호**: HWPX는 `kordoc parse_pages`로만 읽었으며 수정하지 않음.

## 1. 원문 구조 대조

F-014와 달리 이 서식은 학교가 자유롭게 정의하는 평가표가 아니라, 4개 고정 항목(수행경험 10점·공인인증 10점·거리적접근성 15점·상한가격 15점, 합계 50점)에 정해진 배점 구간이 있고 **업체 1곳을 평가**하는 서식임. `기초자료입력!B44:B53`(업체명, R-03) 옆 `C~F`열에 업체별 4개 항목 점수를 입력하도록 구현하고, `F-015_정량적평가` 시트는 선택 업체 순번(`I3`, 인쇄 전용 셀)이 가리키는 업체 1곳의 점수만 `INDEX` 수식으로 표시하는 템플릿으로 구성함. 원본의 서약문·날짜·서명란은 학교명·학년도만 자동 반영하고 서명은 빈칸으로 유지함.

## 2. 구현 범위

| 구분 | 내용 |
| --- | --- |
| 입력 | `기초자료입력!C44:F53` — 수행경험(0~10)·공인인증(0~10)·거리적접근성(0~15)·상한가격(0~15), 정수만 허용 |
| 검증 | `정량평가행검증`(저장 게이트, 점수 4칸 중 일부만 입력 또는 업체명 없이 점수만 입력 시 거부) / `F015업체행완전한가`(출력 게이트, 업체명+4개 점수가 모두 완전·정상 범위일 때만 출력 대상) |
| 출력 | `검증_F015출력가능()`이 완전한 업체가 1곳 이상 있는지 확인하고, `선택된시트목록()`이 완전한 업체마다 `F-015_정량적평가` 시트를 복사해 `I3`만 바꾼 임시 시트를 만들어 F-007/F-014/F-024와 함께 하나의 PDF로 결합함(`F015임시시트생성`/`F015임시시트정리`) |
| A4 | Zoom=100·FitToPages=False·HPageBreaks=VPageBreaks=0으로 1쪽 자연 충족(최초 열 너비가 F-014보다 넓어 VPageBreaks=1로 실패했던 것을 F-014 수준으로 좁혀 수정함) |

## 3. 검증 결과 (`_workspace/03_excel/verify_v1_log.txt`, `교복구매_길라잡이_20260916_v15.xlsm`)

다음 항목이 모두 PASS함: 원문 대조 제목·머리글, 선택 업체 순번(`I3`) 전환 시 4개 항목 점수·합계 50점 반영, `검증_F015출력가능()` 정상/배점 초과/고아 입력 3가지 경로, 최대 길이·특수문자 학교명 반영, PDF 저장 후 임시 인쇄 시트 정리, A4 1쪽 자연 배율. 기존 F-007/F-014/F-024·DB 저장/수정/불러오기·학교검색·절차안내·계약방법안내 회귀도 모두 재통과함.

## 4. 차단 사유 — 저장하기()/수정하기()/불러오기() 연동 제거

- **증상**: `DB_정량평가` 시트(레코드순번·행번호·수행경험·공인인증·거리적접근성·상한가격)를 만들고 `저장하기_실행`/`수정하기_실행`/`불러오기_순번`에 연동했을 때, `Application.Run("검증_저장하기")` 호출이 **응답 없이 무한 대기**함(오류 없이 hang, 강제 종료 필요).
- **원인 조사**: `_trace.txt`에 단계별 추적을 심어 재현한 결과, 정확히 `정량평가복사_기초자료_DB` 호출 직전까지는 로그가 남고 그 이후로는 아무 것도 기록되지 않음 — 즉 이 프로시저 내부(또는 진입 직후)에서 멈춤. 코드는 이미 검증된 `업체복사_기초자료_DB`/`평가복사_기초자료_DB`와 구조적으로 동일하며(같은 방식의 행 삭제 후 재기록, 같은 보호·VeryHidden 시트), 정적 검토로는 무한 루프·모달 대화상자 등 뚜렷한 원인을 찾지 못함. 재현은 100% 확정적이었으나(직접 호출 2회 모두 동일 지점에서 멈춤) 근본 원인은 이번 세션에서 규명하지 못함.
- **조치**: 근본 원인이 불확실한 상태로 핵심 저장 기능(모든 Form ID 공통)을 깨뜨릴 수 없어, `정량평가복사_기초자료_DB`와 `저장하기_실행`/`수정하기_실행`/`불러오기_순번`/`저장경계검증`의 관련 연동 코드를 모두 제거함. `DB_정량평가` 시트와 보호·VeryHidden 설정은 향후 재시도를 위해 남겨 두었으나 현재는 항상 빈 상태임.
- **영향**: F-015 점수는 **같은 세션에서 직접 입력한 값만** 출력(PDF)에 반영됨. 저장 후 다른 레코드를 불러오거나 파일을 닫았다 열면 F-015 점수는 사라지며(업체명은 유지됨), 다시 입력해야 함. 이 한계 때문에 F-015는 F-007·F-014·F-024와 같은 "구현 완료" 목록에 포함하지 않음.
- **다음 조치 후보**: (1) VBA IDE로 직접 열어 `Debug > Step Into`로 `정량평가복사_기초자료_DB`를 한 줄씩 실행해 정확한 정지 지점을 특정, (2) `Application.Run` 대신 워크북을 `Visible=True`로 열고 수동 저장 버튼을 눌러 동일 증상이 재현되는지(자동화 특이 문제인지 VBA 자체 문제인지) 확인, (3) 문제가 계속되면 `정량평가복사_기초자료_DB`를 더 작은 단위(삭제/기록 분리)로 재작성.

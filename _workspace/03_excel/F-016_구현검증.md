# F-016 정성적 평가 구현·검증 (진행 중 — 구조만 추가됨)

- **상태**: `IN_PROGRESS — 시트·DB 구조만 추가함. 저장 검증(정성평가행검증)·저장 연동(정성평가복사_기초자료_DB)·출력 게이트(검증_F016출력가능)·PDF 결합은 미구현. 서식선택_출력에는 "N"(미구현)으로 남겨 잘못 선택되지 않게 함`
- **Form ID**: `F-016`
- **원본 대조 대상**: `교복4차 (2)/교복 매뉴얼 작성서식0908(안정구 추가).hwpx`의 `[9-5] [붙임 3_2] [2단계] 정성적 평가`

## 1. 원문 구조

F-015(사업담당자 평가)와 달리 F-016은 **교복선정위원회**가 평가함. 4개 고정 항목(재질 15점·완성도 10점·A/S 15점·하자보상 10점, 소계 50점)을 각각 5단계(탁월/우수/보통/미흡/불량)로 채점하고, 추가로 **가점·감점 요인**(공정거래위원회 담합 처분 시 -10, 최근 3년 만족도 조사 결과에 따라 -5~+5)이 있음. 사용자 확인 결과 다음과 같이 단순화하기로 함: (1) 5단계는 담당자가 최종 점수 숫자를 직접 입력(항목별 허용 범위로 검증), (2) 가점·감점은 담당자가 판단한 순 가감점을 단일 숫자칸(-15~+5)에 입력.

## 2. 이번에 추가한 것 (구조만)

- `기초자료입력!H44:L53` — 업체별 재질(0~15)·완성도(0~10)·A/S(0~15)·하자보상(0~10)·가감점(-15~+5) 입력 열, `M44:M53`에 완전성 상태 표시 수식(F-015의 `G` 열 패턴과 동일)
- `DB_정성평가` 시트(레코드순번·행번호·재질점수·완성도점수·AS점수·하자보상점수·가감점) — F-015의 `DB_정량평가`와 동일한 구조, 보호(`UserInterfaceOnly`)·VeryHidden 적용
- `F-016_정성적평가` 시트 — F-015와 동일한 "선택 업체 순번(`I3`) + `INDEX` 수식" 템플릿 패턴으로 원문 4개 항목과 가점·감점 요인을 재현. 서약문은 "교복선정위원회 평가위원" 버전으로 반영
- `verify_excel_v1.ps1`의 필수 시트 검사에 두 시트를 반영(개수 17→19)
